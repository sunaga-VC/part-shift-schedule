# シフト調整アプリ

アルバイトの希望シフト登録、日付別共有、管理者集計、確定シフト公開までを一通り操作できる Web アプリです。

## 起動方法

```powershell
cd "C:\Users\admin\Desktop\part_time"
npm install
npm run dev
```

ブラウザで `http://localhost:3000/login` を開き、Supabase に登録したアカウントでログインしてください。

## 画面

### アルバイト

- ホーム
- 希望シフトカレンダー（人数・自分の時間・日付別希望者リスト・登録/編集/削除）
- シフト画面（公開済み確定シフトの確認）

### 管理者

- シフトダッシュボード（集計・絞り込み）
- 週間シフトボード（希望→確定、差分表示）
- シフト対象期間管理
- 必要人数設定
- 確定シフト公開

## 実装済みのルール

- 保存した時点で正式な希望シフト（提出機能なし）
- スタッフID + 日付 で 1 日 1 件
- 実働 = 終了 − 開始 − 休憩（8時間以上は休憩1時間を自動計算）
- 他スタッフには名前と希望時間のみ表示
- 休憩・実働・備考は本人と管理者のみ
- 「未提出」表現は使わず「希望登録あり / なし」
- 編集可否は登録期間で判定（提出状態ではない）
