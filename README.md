# シフト調整アプリ

アルバイトの希望シフト登録、日付別共有、管理者集計、確定シフト公開までを一通り操作できる Web アプリです。

## 起動方法

```powershell
cd "C:\Users\admin\Desktop\part_time"
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## デモの使い方

画面右上の「ログインユーザー」で役割を切り替えます。

1. **田中（アルバイト）** で `/wish` を開き、日付を選んで希望を保存
2. **管理者** に切り替え、`/admin` で希望人数・時間を確認
3. `/admin/board` で希望から確定へ追加・時刻調整
4. `/admin/publish` で公開
5. アルバイトに戻し、`/confirmed` で公開済み確定シフトを確認

データはブラウザの `localStorage` に保存されます。「デモ初期化」で初期状態に戻せます。

## 画面

### アルバイト

- ホーム
- 希望シフトカレンダー（人数・自分の時間・日付別希望者リスト・登録/編集/削除）
- 確定シフトカレンダー（公開済みのみ）

### 管理者

- シフトダッシュボード（集計・絞り込み）
- 週間シフトボード（希望→確定、差分表示）
- シフト対象期間管理
- 必要人数設定
- 確定シフト公開

## 実装済みのルール

- 保存した時点で正式な希望シフト（提出機能なし）
- スタッフID + 日付 で 1 日 1 件
- 実働 = 終了 − 開始 − 休憩（8時間以上は休憩1時間を自動計算）
- 他スタッフには名前と希望時間のみ表示
- 休憩・実働・備考は本人と管理者のみ
- 「未提出」表現は使わず「希望登録あり / なし」
- 編集可否は登録期間で判定（提出状態ではない）
